Fits Overtime Management

Modul ini memudahkan perusahaan dalam mengelola jam kerja dan lembur karyawan secara fleksibel, terstruktur, dan terintegrasi di Odoo 18.

Fitur Addons

  • ☑ OT Request
  • ☑ Master Configuration
  • ☑ Working OT Configuration
  • ☑ Employee Configuration
  • ☑ OT Reporting

OT Request

  • ➤ Digunakan untuk pengajuan lembur karyawan berdasarkan OT Configuration yang telah ditetapkan perusahaan.
  • ➤ Pengajuan lembur disesuaikan dengan konfigurasi karyawan dan periode kerja, termasuk start date dan end date.
  • ➤ Sistem secara otomatis memvalidasi working days dan days off agar pengajuan lembur sesuai dengan kebijakan yang berlaku.

Master Configuration

  • ➤ Digunakan untuk mengelola konfigurasi utama periode kerja lembur sebagai dasar perhitungan OT.
  • ➤ Menyediakan pengaturan Period Configuration dan Name Configuration untuk memudahkan pengelompokan aturan lembur.
  • ➤ OT Request dikonfigurasikan sebagai Working Time yang menjadi acuan dalam proses pengajuan lembur karyawan.

Working OT Configuration

  • ➤ Digunakan untuk mengatur detail lembur melalui OT Lines yang terdiri dari OT 1, OT 2, hingga OT 3.
  • ➤ Setiap OT Line dapat dikonfigurasikan berdasarkan Type Week sebagai penentuan working days dan days off.
  • ➤ Mendukung pengaturan start date dan end date untuk menentukan periode berlaku lembur.

Employee Configuration

  • ➤ Pada halaman Employees, tersedia pengaturan Overtime Configuration di menu Settings.
  • ➤ Konfigurasi lembur yang dipilih akan diterapkan langsung ke masing-masing karyawan.

OT Reporting

  • ➤ Pada halaman OT Reporting, tersedia filter berdasarkan Employee Configuration, start date, dan end date untuk menampilkan data lembur.
  • ➤ Tombol Generate Report digunakan untuk menampilkan hasil lembur sesuai parameter filter ke dalam list laporan.
  • ➤ Data laporan yang ditampilkan sepenuhnya mengikuti konfigurasi dan periode yang dipilih.
  • ➤ Tombol Print PDF berfungsi untuk menghasilkan laporan PDF berdasarkan data hasil filter yang telah digenerate.
